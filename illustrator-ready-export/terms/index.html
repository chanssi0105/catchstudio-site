1Service

Illustrator Ready Export exports selected Figma frames and sections to SVG, PDF, Illustrator-compatible AI, InDesign IDML and Photoshop PSD. Support varies by format and options. Conversion and file generation happen on your device. Selection analysis is free.

2Free trial

The free trial allows up to 3 exports per Figma account within 7 days of the first run, whichever limit is reached first. Each selected export target uses one credit, so a batch uses as many credits as it has targets. Credits are consumed when the server authorizes an export and are not automatically restored if conversion later fails. Contact us if you encounter a problem.

The server verifies trial usage and duration. Changing computers or reinstalling the plugin does not reset the trial, and changing your device clock does not extend it. Free exports require server approval. Network errors, timeouts or server outages stop the export and display a retry message.

3Paid use and payment

This plugin is a one-time purchase. Check the price shown in Figma's checkout. When Figma identifies your account as PAID, you can export without trial usage or time limits, even if the trial server cannot be reached. Figma's own operation and payment status verification remain dependent on Figma's service.

Payment and refund procedures follow Figma's Community purchase guidance. Figma provides purchase and refund support; contact the operator for plugin functionality questions. These terms do not limit consumer rights under applicable law.

4Use and ownership

You may use the plugin with your own Figma account. Process only designs, fonts and images that you are authorized to use and export. Ownership of designs and exported files remains with their existing rights holders. Do not resell plugin code without permission or use the service to bypass trial or purchase verification.

5Checking exported files

Figma and Adobe applications support different features, so effects, fonts, text positioning and colors may differ. AI output is an Illustrator-compatible PDF saved with an .ai extension. Check results in the target application before printing or delivery, and keep the original design. Supported formats and features may vary by plugin version.

6Data processing

The server receives a Figma payment token, free usage count, export count and format name, plugin version, language, elapsed time since the first run and usage events. It does not receive design content, files, names, images or text content. Statistics store only a user ID hash and are retained for 400 days; account records are deleted on request. Processing takes place in AWS's Seoul region. See the Privacy Policy for details.

7Contact and changes

For plugin support or data deletion, email catchstudio25@gmail.com. Changes to functionality, trial conditions or data processing are reflected in the relevant guidance and this page. Do not include payment tokens, passwords or design files in support messages.
